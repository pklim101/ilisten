## 二、标题体系：一条公式打天下，局部微调做实验

### 主公式（精听系列固定使用）

```
【剑19 Test1 Part2】雅思听力逐句精听｜三遍挖空训练｜考点词+双语字幕
```

结构拆解：`【编号锚点】+ 核心搜索词 ｜ 方法卖点 ｜ 功能卖点`

- **【剑19 Test1 Part2】**：方括号编号是"确定性点击锚点"——用户带着明确目的搜索"剑19 test1"，标题前 12 个字符必须完成匹配。永远把编号放最前。
- **雅思听力逐句精听**：主搜索词组，"雅思听力"和"精听"两个词都进来
- **三遍挖空训练**：差异化方法词，筛选目标用户（懂行的人看到"挖空"就知道这是干什么的）
- **考点词+双语字幕**：功能补充，覆盖"雅思听力字幕"等长尾搜索

### 标题纪律

1. **全系列统一格式**，只换 Test/Part 编号——让算法和用户都把你看成"系列"而非散件
2. 标题 ≤ 40 字（超出部分在搜索结果页被截断），实测上面公式 36 字，安全
3. 不同 Part 只改一个词做人群钩子（与封面副标题呼应）：
   - P1：`…三遍挖空训练｜生活对话入门`
   - P2：`…三遍挖空训练｜连读重灾区`
   - P3：`…三遍挖空训练｜多人对话易翻车`
   - P4：`…三遍挖空训练｜学术讲座冲7+`

### 方法论文/衍生内容标题（另一套逻辑：痛点前置）

| 内容 | 标题 |
|---|---|
| 三遍法原理 | 精听三个月没效果？因为你把精听做成了听写 |
| 考点词预判 | 雅思听力的答案词，其实可以提前"算"出来 |
| 错误分类法 | 听力提不了分，是因为你分不清这两种错误 |
| 管线揭秘 | 我写了个程序，自动生成雅思精听视频（附思路） |

规律：**精听视频标题做"搜索"（用户找内容），衍生内容标题做"推荐"（内容找用户）**。前者拼关键词匹配，后者拼痛点共鸣，不要混用。

### A/B 测试安排（冷启动期）

- 第 1-2 周发的前 6 篇精听，3 篇用完整公式、3 篇砍掉"功能卖点"段做对照
- 每篇发布 48 小时后记录点击率（创作中心可见），找出最短且不掉点击的公式后固化
- 衍生内容每条备 2 个标题，首发用一个，48 小时数据差则换另一个（B站支持改标题）

## 三、钩子设计：考点词表 PDF → 关注转化流水线

### 钩子为什么成立

精听视频的 viewers 有一个天然动作：**看完想"拿走"这篇的考点词去复习**。竞品只给笼统的"全套 PDF"，你给的是"**这一篇的**考点词表"——颗粒度更细、和视频强绑定、且管线自动生成零成本。这是你的结构性优势。

### PDF 内容模板（单篇 1-2 页 A4）

```
┌──────────────────────────────────────┐
│ 剑19 Test1 Part2 · 考点词表              │
│ 配套视频：BV号（发布后回填）               │
├──────────────────────────────────────┤
│ 01. Twinning Association  结对协会      │
│     原句：It's great to see so many    │
│     members of the Twinning            │
│     Association here tonight.          │
│     ⚠ 易错点：专有名词，首字母大写        │
│ 02. so many members  …                 │
│ …（每篇 15-25 个考点）                   │
├──────────────────────────────────────┤
│ 使用说明：三遍法自查清单 □□□             │
│ 关注「雅思精听系统训练」领取全套           │
└──────────────────────────────────────┘
```

### 自动生成方案（管线已有全部原料）

你管线里的 `data/annotated.json` 已包含每句的 `text`（原文）、`translation`（翻译）、`highlights`（考点词）——写个脚本（`make_vocab_pdf.py`）读 JSON → 按句提取考点 → 套模板渲染成 PDF（reportlab 或 weasyprint），**并入 `run.sh` 作为出片流水线的最后一步**。每篇视频产出时自动附带考点词 PDF，真正零边际成本。

> 加分项：PDF 最后一页放"7 天打卡表"空白模板，引导用户打印——打印行为 = 高粘性用户信号。

### 领取链路设计（合规版）

```
视频简介：「本篇考点词表 PDF → 关注我，自动回复领取」
    ↓
关注触发自动回复（B站创作中心-自动回复功能）：
  "欢迎！回复对应编号领取考点词表：
   回复【191】= 剑19 Test1 全部考点词
   回复【192】= 剑19 Test2 …（以此类推到后台关键词上限）"
    ↓
用户回复关键词 → 收到网盘链接（或B站工房/专栏链接）
```

**合规红线（重要）**：
- ⚠️ 不要在前 3 个月放个人微信号。新号引流到站外是限流/封禁高危行为，竞品号能挂微信是因为有老号权重。私域引流放到粉丝 1 万以后，且用动态而非简介
- 资料托管用**公开网盘链接**或 **B站专栏**（专栏可插附件），全程站内闭环最安全
- 自动回复关键词上限有限，按 Test 合并打包（1 个 Test = 4 个 Part 合一本 PDF），节省关键词位

### 钩子的数据指标

- 简介点击率不可见，用**代理指标**：每期发布后 48h 内「关注自动回复触发数 ÷ 播放量」，>2% 为健康
- 关键词回复次数分 Test 统计——告诉你哪套真题需求最大，反哺更新优先级

## 四、原创衍生内容规划（版权安全的基本盘）

### 内容矩阵：三个栏目

| 栏目 | 占比 | 形态 | 版权风险 | 功能 |
|---|---|---|---|---|
| **《考点词精讲》** | 50% | 5-8 分钟视频/专栏文章 | 零（自研内容） | 沉淀可搜索资产，长尾流量 |
| **《精听方法论》** | 30% | 6-8 分钟观点视频 | 零 | 立人设、涨信任粉 |
| **《烤鸭问答》** | 20% | 3-5 分钟，回答评论区问题 | 零 | 互动率、社区感 |

### 《考点词精讲》选题库（前 10 期，可直接开做）

素材全部来自你管线的 `annotated.json` 沉淀——把每篇 highlights 按主题归类：

1. 雅思听力最爱考的 20 个"连读陷阱"（would've /'d've/ 类）
2. 数字听写专项：电话号码、价格、日期的英式读法
3. 剑 19 高频场景词：住宿篇 / 旅游篇 / 学术篇（按 Part 场景拆 3 期）
4. 单复数坑：为什么你总是漏掉那个 "s"
5. 同义替换专项：postpone = put off，Part 3/4 的保命技能
6. 英式拼写 vs 美式拼写：答案写错也扣分
7. 专有名词听写：人名地名怎么记笔记
8. 信号词大全：actually / but / the thing is 后面必出考点
9. Part 4 学术词：那些你认识但听不出的词（photosynthesis 类）
10. 考前一周：只刷这 100 个考点词

> 这个栏目做到 20 期后，合订成《雅思听力考点词手册》——这就是你的第一份可售卖/可引流资产，且完全无版权问题。

### 《精听方法论》选题库（前 6 期）

1. 精听不是听写：三遍法的科学原理（脚本已完成，见 05 文档）← 首发
2. 考点词怎么预判：看完题就知道答案藏在哪
3. 两种听力错误，两种完全不同的练法
4. 精听到什么程度可以换材料？（量化标准：三遍后盲听正确率 90%）
5. 每天 20 分钟 vs 周末 3 小时：听力训练的频率原则
6. 从 5.5 到 7.5：精听各阶段的材料选择（剑雅难度地图）

### 发布节奏（与精听视频咬合）

```
周一 18:00   精听视频（剑19 Test1 Part1）
周三 18:00   精听视频（…Part2）
周五 18:00   精听视频（…Part3）
周六 15:00   衍生内容（考点词精讲 / 方法论 轮换）
```

每周 3 精听 + 1 衍生，衍生内容占 25%——既守住版权红线（原创占比），又给算法持续的"知识区创作者"信号。

### 与钩子的飞轮

```
精听视频（引流）→ 领考点词PDF（关注）→ 考点词精讲栏目（留存+信任）
      → 方法论视频（人设）→ 评论区提问 → 烤鸭问答（互动素材）→ 新选题
```

衍生内容的选题全部从"考点词数据 + 评论区问题"里长出来，永远不缺选题，且每条都精准命中已有粉丝的需求。
