
## 2. 参数调整速查

| 想改什么 | 改哪里 | 默认值 |
|---|---|---|
| 每句播放遍数 | `03_rebuild_audio.py` `REPEATS` / 环境变量 | `3` |
| 三遍之间停顿 | `REPEAT_GAP_SEC` | `1.0` |
| 每句三遍后停顿 | `SENT_GAP_SEC` | `3.0` |
| 题目说明段判定阈值 | `01_align.py` `GAP_THRESHOLD` | `4.0` |
| whisper 模型 | `WHISPER_MODEL` | `small`（**不建议改 medium**） |
| 英文字号 | `04_subtitles.py` Style EN Fontsize | `48` |
| 中文字号 | Style ZH Fontsize | `36` |
| 左右内边距 | Style EN/ZH `MarginL`/`MarginR` + `MAX_W_*` | `120`（两处需同步改） |
| 高亮颜色 | `apply_highlights()` 中 `&H000080FF` | 橙红（BGR） |
| 挖空下划线长度 | `underline_len = min(6*n_words+2, 14)` | 每词约 6，封顶 14 |
| 输出分辨率 | `VIDEO_W` / `VIDEO_H` | `1920` / `1080` |
| 背景图 | `BACKGROUND` 环境变量 | `assets/background.png` |

> ⚠️ **改左右内边距时，`MarginL/R` 和 `MAX_W_EN`/`MAX_W_ZH` 必须一起改**，否则折行宽度与边距不一致。

## 3. 故障排查手册

| 现象 | 排查步骤 | 处理 |
|---|---|---|
| **找不到 ffmpeg** | `python3 ielts-video/scripts/ffmpeg_helper.py` | 未装 `imageio-ffmpeg` → `pip install imageio-ffmpeg` |
| **模型下载 502 / 超时** | 检查 `HF_ENDPOINT` | 必须 `export HF_ENDPOINT=https://hf-mirror.com HF_HUB_DISABLE_XET=1` |
| **`av` 报 `metadata_errors`** | `pip show av` | 版本不兼容 → `pip install "av==13.1.0"` |
| **合成进程被杀（exit 137）** | 是否前台运行 | 改为后台运行（`run_in_background`） |
| **对齐成功率低**（matched 数远小于句子数） | 看 `01_align.py` 输出 `对齐成功 N/M 句` | 检查原文是否为**纯正文**；确认音频与原文对应 |
| **题目说明被当成正文**（说明段也循环 3 遍） | 看 `01` 输出的说明段列表 | `GAP_THRESHOLD` 偏大 → 调小（但不可 <3.0，否则正常句间停顿会被误判） |
| **正文句被当成题目说明**（正文不循环） | 同上 | `GAP_THRESHOLD` 偏小 → 调大 |
| **字幕左右被裁切** | 检查 `MarginL/R` 与 `MAX_W_*` 是否一致 | 两者同步设为 `120`；确认走的手动折行分支 |
| **挖空下划线重叠 / 贴标点** | 看 `subtitles.ass` 挖空行 | 确认用的是单条连续下划线（无 `\u2003`） |
| **高亮颜色跨行异常** | 看 `subtitles.ass` 高亮行 | 确认是"先折行后高亮"，不是先高亮后折行 |
| **背景有黑边** | 看 `05_compose.py` 滤镜 | 应为 `force_original_aspect_ratio=increase` + `crop` |
| **背景过曝全白** | 检查是否加了 `eq=brightness` | 该参数是加性偏移，会过曝 → 移除 |
| **背景变成深色渐变** | 是否跑了 `00_background.py` | ⚠️ 见 §5.1，该脚本会覆盖浅色背景图 |
| **DeepSeek 返回解析失败** | 看 `02` 输出 `[警告] 批次 N JSON 解析失败` | 脚本已降级为空标注不中断；可重跑该步 |
| **成片音画不同步** | 核对 `timeline.json` 与音频时长 | 确认 `03` 未被中断、`tmp_audio` 完整 |

## 5. 已知风险与安全事项

### 5.1 ⚠️ `00_background.py` 会覆盖背景图

`batch.sh` 第 35 行会调用 `00_background.py`，而该脚本生成的是**深蓝→深紫的深色渐变背景**，会**覆盖**当前使用的清新浅色背景图 `assets/background.png`。

**影响**：批量出片后背景风格突变，且深色背景与深色字幕冲突导致字幕看不清。

**建议处理**（二选一）：
```bash
# 方案 A：从 batch.sh 移除该调用（推荐）
#   删除 batch.sh 中第 33-35 行的 00_background.py 调用

# 方案 B：跑批量前备份，跑完恢复
cp ielts-video/assets/background.png /tmp/background_backup.png
bash ielts-video/batch.sh resource ielts-video/out
cp /tmp/background_backup.png ielts-video/assets/background.png
```

### 5.2 ⚠️ API Key 硬编码（安全缺陷）

`02_annotate.py` 曾把 API Key 作为 `os.environ.get()` 的**默认值**写死在源码中（已于 V3.1 修复）。

**风险**：密钥随代码提交到 Git 即公开泄露，任何人可盗用额度；且环境变量缺失时静默使用，掩盖配置错误。

**当前实现（已修复）**：
```python
API_KEY = os.environ.get("DEEPSEEK_API_KEY")
if not API_KEY:
    raise SystemExit("[错误] 未设置 DEEPSEEK_API_KEY 环境变量。...")
```

> 🔴 **若该密钥曾出现在任何公开仓库/提交记录中，请立即到 DeepSeek 控制台轮换（revoke）该密钥。**
> Git 历史中的密钥即使后续删除仍可被检出，唯一有效手段是**轮换密钥本身**。

### 5.3 其他注意事项

| 项 | 说明 |
|---|---|
| 中间产物共用 | `data/` 下产物在批量处理时**逐篇覆盖**，`tmp_audio/` 会累积（可定期清理） |
| 磁盘占用 | 单篇中间产物 ≈ 13 MB（音频）+ 切片目录；成片 ≈ 60 MB |
| 模型缓存 | whisper 模型首次下载后缓存于 `~/.cache/huggingface`，无需重复下载 |
| 后台任务 | 合成约 3.5 分钟/篇，批量多篇时串行总耗时线性增长 |
